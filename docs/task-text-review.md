## Breathing (4 tasks)

| Phase | Task Name | Description |
|-------|-----------|-------------|
| 1 (Days 1-5) | Morning Breath Check | Take 5 deep belly breaths upon waking |
| 2 (Days 6-10) | Stress Reset | 4-7-8 breathing when stressed (inhale 4s, hold 7s, exhale 8s) |
| 3 (Days 11-15) | Box Breathing Break | 5-minute box breathing during lunch (4s inhale, 4s hold, 4s exhale, 4s hold) |
| 4 (Days 16-20) | Evening Wind-Down | 10 slow breaths before bed, extending exhale |

## Sleep (4 tasks)

| Phase | Task Name | Description |
|-------|-----------|-------------|
| 1 (Days 1-5) | Consistent Wake Time | Wake up at the same time every day (within 30 min) |
| 2 (Days 6-10) | Screen Curfew | No screens 30 minutes before bed |
| 3 (Days 11-15) | Cool & Dark | Bedroom temp below 68°F, blackout conditions |
| 4 (Days 16-20) | Wind-Down Ritual | 15-min relaxation routine (reading, stretching, journaling) |

## Hydration (4 tasks)

| Phase | Task Name | Description |
|-------|-----------|-------------|
| 1 (Days 1-5) | Morning Hydration | Drink 16oz water within 30 min of waking |
| 2 (Days 6-10) | Water Tracking | Log and drink at least 64oz total daily |
| 3 (Days 11-15) | Electrolyte Balance | Add electrolytes or mineral-rich water once daily |
| 4 (Days 16-20) | Pre-Meal Hydration | Drink 8oz water 15 min before each meal |

## Nutrition (4 tasks)

| Phase | Task Name | Description |
|-------|-----------|-------------|
| 1 (Days 1-5) | Protein First | Eat protein within 1 hour of waking |
| 2 (Days 6-10) | Eat the Rainbow | Include 3+ colors of vegetables daily |
| 3 (Days 11-15) | Mindful Eating | No screens during at least one meal, chew thoroughly |
| 4 (Days 16-20) | Fiber Focus | Aim for 25-30g fiber (track one day per week) |

## Movement (4 tasks)
